# APM-Lua

Набор скриптов Lua для ArduPilot / ArduCopter, расширяющих поведение в полёте во время работы прошивки.

> ## ⚠️ Условия применимости
> **Все скрипты Lua проверены на реальном аппарате только с соответствующей версией прошивки; на любой другой версии прошивки они могут не работать.**

## Назначение репозитория

В репозитории размещены скрипты Lua, написанные для прошивки APM (ArduPilot / ArduCopter). Скрипты выполняются на контроллере полёта с помощью встроенного в ArduPilot движка Lua-скриптов и расширяют или ограничивают поведение в полёте без изменения исходного кода прошивки — например, динамически ограничивают скорость ручного снижения в зависимости от высоты полёта.

Репозиторий содержит только скрипты, которые можно напрямую скопировать в каталог `APM/scripts/` на SD-карте контроллера полёта. Он не включает исходный код прошивки, конфигурацию наземной станции и сторонние зависимости.

## Поддерживаемые версии прошивки

- Прошивка: ArduCopter 4.6.3 и 4.7.0 (мультикоптер).
- Адаптация параметров: версия 4.6.x использует `PILOT_SPEED_DN` / `PILOT_SPEED_UP` (единица: см/с); версия 4.7.x использует `PILOT_SPD_DN` / `PILOT_SPD_UP` (единица: м/с). Встроенный адаптер автоматически определяет пару и требует наличия ровно одной из двух пар; в противном случае скрипт только контролирует параметры и ничего не записывает.
- Другие версии: совместимость не реализована. Любое изменение имён или семантики параметров может привести к неработоспособности скриптов или к неожиданному поведению.

## Состав скриптов

| Скрипт | Прошивка | Краткое описание |
| --- | --- | --- |
| `near_ground_slowdown.lua` | ArduCopter 4.6.3 / 4.7.0 | В режимах AltHold / Loiter ограничивает скорость ручного снижения по высоте над точкой home: 0,50 м/с в диапазоне 2–5 м, 0,10 м/с на высоте ≤ 2 м |
| `near_ground_slowdown_stage2_0p2.lua` | ArduCopter 4.6.3 / 4.7.0 | То же, что выше, но для диапазона ≤ 2 м порог увеличен до 0,20 м/с |

Определения параметров, коды состояний и поля журнала для каждого скрипта приведены в `README.md` соответствующего функционального каталога.

## Указания по использованию

- Скопируйте скрипт в каталог `APM/scripts/` на SD-карте контроллера полёта и убедитесь, что `SCR_ENABLE = 1`.
- Загружайте только один скрипт на одну функцию; два варианта `near_ground_slowdown` используют общую таблицу параметров `NGC_` и не должны загружаться одновременно.
- Скрипты записывают только параметры скорости снижения и не отправляют команды arm / disarm / двигателей / режима полёта; посадка выполняется штатным автоматическим disarm по параметру `DISARM_DELAY`.
- Высота берётся из положения EKF относительно точки home, а не из истинной высоты над землёй; рельеф местности и барометрический дрейф влияют на решение.
- При первом использовании снимите воздушные винты и проверьте на земле запись и восстановление параметров, после чего выполняйте полёт.
